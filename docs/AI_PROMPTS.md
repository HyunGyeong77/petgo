# Profile Page 제작

위치:
`education/[category]/[level]/[id]/*`

요구사항:
- 포스트 페이지 제작
- `education/[category]/[level]/[id]/page.tsx` 라우팅 대상 파일
- 디폴트 색상
  - #f59e0b,
  - #ff9a3c,
  - #ff6b6b,
  - #ff9a3c1a,
  - #111827,
  - #fef3c7
- 뒤로가기 버튼 포함
- article 프로퍼티
  - title / 제목
  - level / 수준
  - readtime / 읽는 시간
  - content / 내용
